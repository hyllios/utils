`mgb2.fc`: real-space interatomic force constants for MgB2, generated by
this project's own `ph.x` (4x4x4 q-mesh) + `q2r.x` pipeline
(`waw.interfaces.quantum_espresso.write_ph_input`/`write_q2r_input`),
hexagonal P6/mmm, a=3.086 A, c=3.523 A.

Unlike `diamond_phonon/diam.ifc` (ibrav=2, a standard Bravais lattice),
this file is `ibrav=0` -- this project's own universal QE convention
(`write_pw_input` always sets `ibrav=0`, explicit `CELL_PARAMETERS`) --
so q2r.x writes 3 extra lines of lattice vectors right after the header
that `diam.ifc` doesn't have. It also exhibits a genuine QE cosmetic
quirk: the second species' symbol ('Mg') prints as an all-blank
CHARACTER(LEN=3) field between the quotes (`' '` instead of `'Mg '`),
which a naive quote-then-whitespace split silently misparses. Both of
these are why this fixture exists: `diam.ifc` alone didn't catch either
edge case, and this project's own phonon pipeline will always hit
`ibrav=0`.

Used by `tests/test_analysis_phonon.py::TestReadForceConstantsIbrav0`.
